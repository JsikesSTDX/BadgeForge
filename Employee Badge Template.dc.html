Specification
54 × 89 mm portrait, printed edge to edge. Lanyard slot 13.5 × 3 mm, centred, 5.7 mm from the top edge. The class banner runs the full height of one edge; the lower field on both faces is Standex Gray #53565A. Photo well is a circle with a class-coloured ring; muster code is a single alphanumeric character. Type is Source Sans Pro (Arial substitute where unavailable).
